
# Ejercicio

Caada ejercicio otorga un punto del supuesto práctico. Generalmente, solo necesitas añadir o modificar una línea de código para conseguir cada apartado.

1. Establece el color del fondo de todo el _body_ con el valor de la variable _--bg-purple_ 
2. Establece un valor _alt_ adecuado para mejorar la accesibilidad a la imagen `<img src="./images/hero-product-ui.png" alt="" />`
3. El *logo* de la Web crece demasiado. Establece la propiedad CSS  adecuadamente para crezca , como mucho, *250px* de ancho.
4. El texto _El mejor trabajo en equipo comienza con un centro digital_ es demasiado pequeño, sobretodo en pantallas grandes. Utiliza una unidad _CSS relativa_ con un valor aproximado para que el tamaño de la fuente sea mayor y se lea mejor.
5. El texto _PRUEBALO GRATIS_ del botón no tiene suficiente contraste. Usa un color adecuado para el fondo blanco.
6. El grosor del texto de los botones no es adecuado. Aumenta el `font-weight` a `700` para *todos* los `<button>`.
7. La barra de navegación no está distribuyendo los elementos como en el diseño original. Convierte la barra en un contenedor flexible. Además, debe separar el logo y los iconos de menú. Finalmente, todos los elementos deben estar alineados en el eje vertical o _cross axis_ (3 líneas de código)
8. Maqueta adecuadamente los logos de las redes sociales que se encuentran en el _footer_ (2 líneas de código)

## Media queries

9. En pantallas con un viewport *superior a 768px* queremos que los elementos del _header_ se coloquen uno al lado del otro para aprovechar el espacio disponible. Es decir, a la izquierda debe quedar el texto, y a la derecha, la captura de pantalla de la aplicación _Slack_
